# 走线路径约束与整理

`pcb_route_track` 和 `pcb_auto_route_nets` 使用 `src/routing-geometry.ts` 中同一套路径策略。手工给定路径和内置自动路径都要经过角度约束及障碍复查。

当前改动处于实现完成、等待测试的阶段；尚未编译、执行测试或连接真实 PCB 验证。

## 参数

坐标及距离单位均为 mil。

| 参数 | 默认值 | 行为 |
| --- | --- | --- |
| `angleMode` | `octilinear` | 允许水平、垂直和 45° 对角线。`orthogonal` 仅允许水平/垂直；`free` 显式允许任意角度。 |
| `cornerStyle` | octilinear 为 `chamfer`，其余为 `preserve` | 倒角模式用 45° 过渡整理直角；空间不允许且不是保护锚点时，预检报错。 |
| `chamferDistance` | 10 | 倒角沿相邻线段回退的目标距离，必要时缩小；不会吃掉相邻倒角。 |
| `minSegmentLength` | 1 | 整理后仍短于该值的线段单独提示，不为消除短线而移动连接端点。 |
| `maxDeviation` | 10 | 整理后的整段路径必须处于原始路径的该距离范围内。 |
| `angleToleranceDeg` | 0.01° | 读回角度检查容差；限制在 0–1°。生成路径以共轴/等量 XY 增量构造，不靠该容差放行斜线。 |
| `protectedIndices` | 空 | 仅单条路径接口：必须保留的中间点下标；首尾以及落在已有同网铜外框内的点自动保护。 |
| `clearance` | 单条 6、自动 15 | 统一保守障碍检查间距，仍需原生 DRC 核对工程中各类具体间距规则。 |
| `dryRun` | false | true 只读当前环境并返回规划结果，不创建图元、重建铺铜或运行 DRC。 |

例如先调用 `pcb_route_track`：

```json
{
  "net": "SWDIO",
  "layer": 1,
  "width": 6,
  "points": [{"x": 482.3, "y": 669.3}, {"x": 481.5, "y": 803.1}],
  "angleMode": "octilinear",
  "cornerStyle": "chamfer",
  "dryRun": true
}
```

返回 `points` 是整理后的坐标，`changed` 表示路径是否变化，`issues` 区分错误和提示，`ready` 表示能否通过本次预检。该示例需在对应网络的实际板子上预览；文档中的坐标不是通用位置。

## 路径与连接的处理

- 不把焊盘/过孔位置整体吸附到某个网格。首尾坐标保留，通过水平、垂直和 45° 过渡解决不共轴端点。
- 移除重复点，合并共线段，并在偏移预算和障碍约束内简化冗余折线。自动候选路径的选择计入转弯代价。
- 锚点优先于倒角。连接锚点处的直角会保留并提示，避免把一个分支接点切掉。
- 每次替换线段及倒角后复查障碍；最终还检查整段路径的偏移范围。失败不强连，也不以任意角度作为隐式降级方案。
- 单条路径预检全部完成后才开始创建线段。原生 API 若中途失败，错误包含已创建的图元 ID，不宣称操作具有原子性。

## 环境检查与写入后检查

固定焊盘、走线、过孔、弧线、填充和区域使用原生包围盒作保守障碍。复杂形状可能产生误报。自动铺铜的边界不作为整块实心障碍，写入后重建铺铜。板框使用包围盒约束，凹形板框及精确间距需要原生 DRC。

写入后读取仍保留创建 ID 的线段，检查其实际角度及短线段。若 EDA 合并/拆分导致 ID 缺失，`geometryVerified` 为 false，并返回 `missingPrimitiveIds`，需要整板检查；铺铜重建或读回失败也会明确报告。

新增 `pcb_check_route_geometry` 是只读工具，支持按网络/铜层筛选，报告：

- 非标准角度、零长度和短线段；
- 同层端点处的普通二度节点转角；
- 焊盘/过孔锚点转角提示，以及排除的多分支节点数。

它不检查连通性或替代 DRC，也不是完整的铜皮拓扑求交。内置自动布线结束时同时返回此几何检查与 DRC；`routedNets` 同时要求该网络的连接和几何检查通过。

`pcb_execute_code` 仍是原始 JavaScript 执行通道。直接调用 `eda.pcb_PrimitiveLine.create` 会绕过路径整理，不会被偷偷改写；常规布线应使用 `pcb_route_track`。原始代码布线后应单独运行几何检查与 DRC。

`scripts/port-plugin.mjs` 会将共享几何函数一并序列化进 EDA 处理器。只更新生成文件、暂不自检时使用：

```bash
node scripts/port-plugin.mjs --generate-only
```

本轮在测试前停止。后续验证需覆盖以下内容：

1. 编译及生成代码语法检查；原有测试中“默认仅正交”的断言需改为显式 `orthogonal` 兼容用例，并新增默认 octilinear 用例。
2. 使用本次 SWDIO、NRST、HSE 的不共轴端点复现：首尾必须精确保留，输出不得直接倾斜。
3. 水平/垂直/对角、负方向、重复点、连续直角、回折、短段与保护锚点；倒角不得重叠或越界。
4. 整理前可用而倒角后碰障碍、凹形路径的中间空白区域、偏移预算累计；预检失败必须零写入。
5. 预览模式零创建/零重建，MCP 工具和内置 Agent 参数都能到达处理器。
6. 模拟写入中断、ID 替换、读回失败及铺铜失败；确认返回未验证状态或已创建 ID。
7. 只读整板检查对多分支节点、焊盘内转角、过孔锚点的分类。
8. 在独立测试工程中验证 EDA 原生图元、角度读回、铺铜重建及 DRC；不在用户正在手工修正的板子上运行。
